# CLI Component

The CLI is the primary scriptable interface for identity management, cryptographic operations, and server interaction.

## Key Capabilities

- create and switch identities
- import/export public identities
- sign/verify messages
- encrypt/decrypt messages and files
- publish/fetch identities via server endpoints
- issue and push revocations
