# Email Chrome Extension

EBP ships a Chrome-compatible extension for webmail encryption/signing and decrypt/verify workflows via the local GUI backend API.

## Supported Webmail Targets

- Gmail
- Outlook (web)
- Proton Mail

## Integration Model

- Extension runs in the browser/webmail context.
- Crypto operations are coordinated with local EBP backend APIs.
