THE DESIGN DIRECTION

Privacy, with a little breathing room.

A proposed redesign of EBP’s mail, identity, contact, and crypto workflows.

01 / Familiar first

Mail opens into a three-column workspace. Mobile uses a list → detail flow and a persistent bottom navigation.

02 / Security in context

Sender verification is separate from encryption. Readable status labels open an explanation; technical fingerprints stay one step deeper.

03 / Progressive disclosure

Daily conversations lead. Identity management and cryptographic utilities have dedicated, quieter spaces.
