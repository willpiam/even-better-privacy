Post-Quantum Identity + Messaging

A practical successor to PGP, built for the next era of cryptography.

EBP pairs modern post-quantum signing and encryption into one simple to use identity management tool.

Check Out the Project Verify Signatures

Why EBP

Post-Quantum by Design

Uses ML-DSA / SPHINCS+ style signatures and ML-KEM style encryption workflows instead of legacy PGP assumptions.

Identity-Centered Security

Your identity combines signing and encryption keys, with a clear fingerprint for sharing and verification.

Real-World Controls

Includes revocation support when keys or details need to be retired.

How It Works

  1. Generate an identity (signing key + encryption key).
  2. Share your public identity and fingerprint.
  3. Import contacts, then sign/verify and encrypt/decrypt messages.
  4. Use the Chromium email plugin to sign/encrypt and decrypt/verify in supported webmail.
  5. Revoke details or full identities if trust changes.
