                    Account Setup (Local Device)

                    Choose a provider to connect this account.

                    Mail credentials are used by the local backend on this PC. They are not sent to your remote EBP key server.

                    How to Connect Your Email

                    Gmail: turn on 2FA in your Google account, then create an App Password and use that in EBP as your IMAP/SMTP password. Typical settings: imap.gmail.com:993 (TLS on) and smtp.gmail.com:465 (TLS on).

                    Proton Mail: use Proton Mail Bridge for desktop IMAP/SMTP access. Enter the Bridge host/ports and the Bridge-generated username/password in EBP.

                    All Others: this works with most providers the same way. Use your provider's IMAP + SMTP settings, enable secure ports/TLS, and use an app-specific password if your provider requires it.

                        Project Info

                        About the EBP (Even Better Privacy) project

                        What is EBP?

                        EBP (Even Better Privacy) is a post-quantum cryptographic identity and messaging system. It enables users to create cryptographic identities, sign messages, encrypt communications, and publish identities to servers — all using quantum-resistant algorithms.

                        The system uses Dilithium or SPHINCS+ for digital signatures, and Kyber for key encapsulation (encryption). These algorithms are designed to be secure against attacks from both classical and quantum computers.

                        ⚠️
                        Local Use Only

                        This GUI is designed as a web interface but is intended only for local use. It runs a local backend server on your machine and should not be exposed to the public internet. Your private keys never leave your device.

                        Source Code

                        EBP is open source. You can view the source code, report issues, and contribute on GitHub.

                        View on GitHub

                        How to Use

                        1. Create an Identity: Go to the Identities page and generate a new identity with a secure password. Your identity contains your public/private key pairs for signing and encryption.

                        2. Add Contacts: Import contacts by pasting their public identity JSON, or fetch them from a server using their fingerprint.

                        3. Sign & Verify: Sign messages to prove they came from you. Others can verify your signature using your public key.

                        4. Encrypt & Decrypt: Encrypt messages so only the intended recipient can read them. Optionally sign encrypted messages for authentication.

                        5. Publish: Optionally publish your public identity to a server so others can discover and communicate with you.
