# EBP Managed Mail Server (Stalwart)

This directory runs the mail server behind EBP's "Get started" onboarding
wizard. Users pick `username@<MAIL_DOMAIN>`; the EBP key server (on Render)
creates the mailbox here through Stalwart's JMAP management API.

Render cannot host this part: Render exposes only one HTTPS port to the
internet (no inbound 25/465/587/993) and blocks outbound port 25 on every plan.

```
clients --(signed signup, HTTPS)--> key server (Render) --(JMAP x:Account/set)--> Stalwart (VPS)
clients --(IMAP 993 / SMTP 465)---------------------------------------------> Stalwart (VPS)
```

## 1. Buy the domain

Any registrar works; mailbox count is unlimited because Stalwart hosts the
mail. Cloudflare Registrar (at cost, ~$10.50/yr for `.com`) or Porkbun are the
easiest. Recommended name: `pqpost.com`.

## 2. Get a VPS with port 25

- **Hetzner Cloud CX22** (~4 EUR/month, 2 vCPU, 4 GB). Outbound port 25 is
  blocked on new accounts; open a support request to unblock it after the first
  invoice is paid.
- **Vultr** is the fallback (also needs a port 25 unblock request).
- **Avoid DigitalOcean**: it blocks SMTP and rarely unblocks.

Install Docker and the compose plugin, then open TCP 25, 443, 465, 587, 993 in
the firewall. Keep 8080 closed (it is bound to 127.0.0.1).

## 3. DNS records

Replace `pqpost.com` and `203.0.113.10` with your domain and VPS IP. On
Cloudflare, every record pointing at the VPS must be **DNS only** (grey cloud).

| Type | Name | Value |
| --- | --- | --- |
| A | `mail` | `203.0.113.10` |
| MX | `@` | `mail.pqpost.com` (priority 10) |
| TXT | `@` | `v=spf1 mx -all` |
| TXT | `_dmarc` | `v=DMARC1; p=quarantine; rua=mailto:postmaster@pqpost.com` |
| TXT | `<selector>._domainkey` | value generated by Stalwart (step 5) |

Optional: MTA-STS (`_mta-sts` TXT + `mta-sts.` host) and TLS-RPT once mail flows.

**Reverse DNS (PTR):** in the VPS provider panel set the IP's PTR to
`mail.pqpost.com`. Without it, Gmail and Outlook will reject or spam-folder mail.

## 4. Start Stalwart

```bash
cd mail-server
cp .env.example .env   # edit MAIL_HOST
docker compose up -d
docker compose logs stalwart   # prints the first-run admin credentials
```

Open the web admin through an SSH tunnel:

```bash
ssh -L 8080:127.0.0.1:8080 root@203.0.113.10
# then browse http://localhost:8080
```

## 5. Configure Stalwart (web admin)

1. Finish the bootstrap wizard: hostname `mail.pqpost.com`, RocksDB storage.
2. **TLS:** enable the Let's Encrypt ACME provider for `mail.pqpost.com`.
3. **Domain:** create `pqpost.com`, then generate a DKIM key and publish the
   TXT record it shows. This classical Stalwart key is temporary. EBP should
   later own DKIM signing and move it to a post-quantum algorithm once
   receivers can verify one. See
   `wiki/analysis-ebp-managed-email-onboarding.md`.
4. **Submission policy:** require authentication on 465/587; never relay for
   unauthenticated clients.
5. **Limits:** set an outbound rate limit per account (e.g. 100 messages/hour)
   and a default disk quota.
6. **Reserved accounts:** create `postmaster@` and `abuse@` and route them to
   your own inbox.
7. **API key for the key server:** create an admin-scoped API key (or a custom
   role) with at least `sysAccountCreate`, `sysAccountUpdate`,
   `sysAccountDestroy`, `sysAccountGet`, and `sysDomainGet`. Copy the token.
8. Look up the domain's JMAP id (Management > Domains, or `x:Domain/get`).

## 6. Configure the key server (Render env vars)

| Variable | Example | Purpose |
| --- | --- | --- |
| `MAIL_SIGNUP_ENABLED` | `true` | Turns on `/api/v1/mail/signup` (default off) |
| `MAIL_DOMAIN` | `pqpost.com` | Address domain |
| `MAIL_HOST` | `mail.pqpost.com` | IMAP/SMTP host returned to clients |
| `STALWART_ADMIN_URL` | `https://mail.pqpost.com` | Stalwart HTTPS base URL |
| `STALWART_ADMIN_TOKEN` | `...` | API key from step 5.7 |
| `STALWART_DOMAIN_ID` | `b` | JMAP id of the domain (looked up automatically when unset) |
| `MAIL_QUOTA_BYTES` | `1073741824` | Per-mailbox disk quota (default 1 GiB) |

Optionally point the existing verification mailer at Stalwart too:
`SMTP_HOST=mail.pqpost.com`, `SMTP_PORT=465`, `SMTP_SECURE=true`,
`SMTP_USER=noreply`, `SMTP_PASS=...`, `SMTP_FROM=noreply@pqpost.com`.

## 7. Smoke test

```bash
curl -s https://<key-server>/api/v1/mail/signup/config
# {"enabled":true,"domain":"pqpost.com","imap":{...},"smtp":{...}}
```

Then run the onboarding wizard in the GUI or mobile app and send a message to
an outside Gmail address. Check headers for `dkim=pass`, `spf=pass`,
`dmarc=pass`.

## Operations notes

- **Deliverability:** a new domain and IP start with no reputation. Expect
  spam-foldering for the first weeks; keep volume low and DMARC aligned.
- **Abuse kill switch:** set `MAIL_SIGNUP_ENABLED=false` on Render to stop new
  signups instantly. Existing mailboxes keep working.
- **Backups:** snapshot the `stalwart-data` and `stalwart-etc` volumes.
- **Upgrades:** the image is pinned to the `v0.16` minor series; read
  Stalwart's `UPGRADING/` notes before moving to a new minor version.
